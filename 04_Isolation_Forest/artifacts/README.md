# Model artifacts

`isolation_forest_b6b.joblib` is generated by `training/train.py` and contains:

- A canonical single Isolation Forest model for diagnostics.
- A bootstrap ensemble (default 25 members; 300 trees per member).
- Per-member training medians and OOB anomaly-score reference distributions.
- The 20-feature schema, full-training medians, feature references/ranges, and metadata.

At inference, `if_mu` is the mean member-specific relative anomaly percentile, and `if_sigma_squared` is sample variance across member percentiles. They describe anomaly severity and ensemble disagreement—not a calibrated fraud probability/variance. See `analysis/mu_sigma_methodology.md`.

Rebuild the bundle from the original dataset with the current `training/train.py` if you change the schema or model configuration.


Raw live rows should be scored with `--input-format raw-live`; the inference module trims surrounding column-name whitespace and applies the verified signed-log1p transform to the documented 14 features. See `config/feature_schema.json` and `analysis/live_input_compatibility.md`. The inference output also reports `if_prediction`, `input_quality_status`, missing-feature counts, and training-range diagnostics.
