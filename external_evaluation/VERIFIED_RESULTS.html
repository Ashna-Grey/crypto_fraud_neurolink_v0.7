Poison-Hunter dataset and pilot diagnostics

Ground truth: 5,890 phishing and 1,154 benign unique Ethereum addresses; 5,729 detector-positive entries are a subset of the phishing ground truth and are NOT another test set.

Manifest: 100 phishing + 100 benign, zero D2 overlap across 10,000 known training addresses.

Pilot: four completed collections all yielded MANUAL_REVIEW without probability; one collection failed with IncompleteRead. Therefore external accuracy, precision and F1 are not calculable, rather than zero or 100%.

What the add-on does

run.py probes the deployed API contract, retrieves Alchemy transfers with retries and pagination, resumes cached pages, reconstructs frozen feature names, sends unlabeled inputs to NeuroLink and produces per-wallet prediction tables and provisional metrics.

Use python -m external_evaluation.run --probe-only, then python -m external_evaluation.run --max-wallets 5, then python -m external_evaluation.run --max-wallets 200 in PowerShell after setting the Alchemy RPC URL in your environment.

D1 train/test independence is limited by prior experimentation. Poison-Hunter specializes in address-poisoning; benign sampling and feature mismatch can create distribution shift. Results from incomplete histories or imputed token fields are diagnostic only.
